Pour

  • Toujours clair où on est
  • Zéro interaction nécessaire

B — Sidebar réduite (icônes) / étendue (labels) au clic

Un bouton ☰ bascule entre mode icônes compact (~50px) et mode étendu avec labels (~200px). Maximise l'espace contenu.

Pour

  • Plein écran quand on veut
  • Pattern connu (VS Code, Slack)

Contre

  • Un clic de plus pour voir les labels

C — Sidebar fixe avec groupes sémantiques

Même largeur fixe, mais les items sont groupés par thème : "Courses", "Cuisine", "Config". Donne une hiérarchie visuelle sans interaction supplémentaire.

Pour

  • Organisation claire à la lecture
  • Scalable si l'app grandit

Contre

  • Plus verbeux pour 5 items seulement
