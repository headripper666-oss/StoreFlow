Comment ajouter des tags à une recette ?

Choisissez le style d'interface qui vous semble le plus naturel

Pâtes à la carbonara
🍝 pâtes × 🐷 porc × + Ajouter un tag
💡 Suggestions : porc, fromage, rapide, soir...

A — Chips + autocomplétion

Les tags s'affichent comme des étiquettes. Un clic sur "+ Ajouter" ouvre un champ avec des suggestions basées sur vos tags existants. On peut aussi taper un nouveau tag.

Pâtes à la carbonara
✓ pâtes ✓ porc poulet bœuf riz végétarien + nouveau...

B — Palette de tags

Tous les tags existants sont visibles d'un coup. On clique pour activer/désactiver. Un bouton "+" permet d'en créer un nouveau. Rapide quand on a peu de tags.

Pâtes à la carbonara
pâtes × porc × Taper un tag...
📝 pâtes
🐷 porc
🍗 poulet

C — Champ de saisie type Gmail

Un seul champ de texte dans lequel on tape. Une liste déroulante affiche les tags existants au fil de la frappe. Entrée pour confirmer. Familier pour les habitués des applis modernes.
